#Ejercicio 1- Diapositiva 123

##Solución
Se pedía que se añadiese un Dialog para poder añadir un nuevo producto.
Se ha creado un nuevo objeto llamado Producto2, uno de los atributos de este objeto es de tipo Uri, que será el que guardará los datos
de la imagen que se elija al pulsar el botón.

Para poder mostrar los datos de ese nuevo producto se añadio la librería Coil para poder usar el método AsyncImage que nos permitía usar
las URI
